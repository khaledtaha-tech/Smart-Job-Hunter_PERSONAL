SMART JOB HUNTER — تثبيت هوستنجر

هذه نسخة خفيفة تعمل على PHP + MySQL ومناسبة لاستضافة cPanel/Hostinger.

1) أنشئ قاعدة MySQL ومستخدمًا لها من لوحة الاستضافة.
2) ارفع جميع ملفات نسخة الإصدار إلى public_html مباشرة.
3) افتح رابط الموقع وسيتم توجيهك إلى install.php عند أول تشغيل.
4) أدخل بيانات MySQL ثم أنشئ حساب الدخول.
5) بعد نجاح التثبيت ستظهر شاشة تسجيل الدخول.

مهم:
- لا ترفع أو تشارك ملف config.php بعد إنشائه.
- المزايا المتاحة تعتمد على الإصدار: Basic أو Standard أو Premium، بينما Personal مفتوح بالكامل.
- لا تعدّل product-config.php في النسخة المباعة إلا عند ترقية العميل إلى إصدار أعلى.
